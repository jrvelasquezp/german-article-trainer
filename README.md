# German Article Trainer

Embedded electronic system for supporting the training of
German grammatical gender through noun-article association.

## Status

Early development / academic project.

## Academic context

- UNAD - Electronic Engineering
- Course 203059 - Proyecto de Grado
- Planned degree option: Applied Project

## Development strategy

The project follows three parallel work tracks:

- COURSE: academic activities for course 203059
- PA: Applied Project preparation and execution
- ENG: technical development and validation

## Reference platform

Raspberry Pi 4 Model B is currently used as the primary
development integration and hardware validation platform.

The system architecture is intended to remain independent
from a specific processing platform wherever practical.

## Repository scope

This repository contains:

- academic documentation;
- research and state of the art;
- system requirements;
- hardware and software architecture;
- implementation;
- experimental prototypes;
- verification and validation;
- Applied Project documentation.
